# FM-1 Big Screen builds

Unofficial **Big Screen** builds of FM-1 firmwares from [The Firmware Hub](https://thefirmwarehub.com): each one is its
author's own firmware, built from their published source with a small addition, so its screen shows big in the free
[FM-1 Big Screen](https://github.com/pfkellogg/fm1-mirror) app (Mac, Windows, Linux) and
[FM-1 Big Screen + Spyglass](https://github.com/pfkellogg/fm1-mirror-spyglass-android) (Android, Fire TV), with
**Big Knobs** and **Key Lights** where the firmware allows. Pick one and see what it looks like at
**[aikellogg.com › Big Screen FWs](https://aikellogg.com/#/make-big-screen)**.

**172 builds.** Every firmware here belongs to its author and keeps its own license; the credit, the license and the
exact source (repository and commit) are in the table, and each build's `.patch` is the complete set of changes.
These builds are not made or supported by the authors: problems with a build go to
[this repository's issues](https://github.com/pfkellogg/fm1-big-screen-builds/issues), not to them.
**Authors:** if you'd rather yours weren't here, or you'd like Big Screen in your own release, open an issue or write
through [aikellogg.com](https://aikellogg.com) and it's done. Charles Vestal's firmwares are never built here.

**Firmware authors:** the best-practice guide for FM-1 Big Screen, and a free fix for yours:
**[aikellogg.com › Fix your firmware](https://aikellogg.com/#/fix-your-firmware)**
([video](https://youtu.be/En7lYeFrhkk)). These builds follow The Firmware Hub every night at midnight (new and updated
firmwares built again; a firmware that has Big Screen in its own release is never built here: its own file is the download).

**Before installing:** back up your FM-1 with [M-Flasher](https://github.com/jvitkauskas/m-flasher) (it saves
everything and puts it all back). These are untested on most units: install at your own risk. Melodee's build has a
resources file too: install the `.fwsc`, then send `-res.bin` with Melodee's own `tools/fm1_resources.py`.
